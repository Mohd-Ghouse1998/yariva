## Additional Phase 1 Notes

- `prisma/` remains at repo root for schema, config, and migrations.
- `src/database/prisma` is the NestJS runtime wrapper around Prisma Client.
- `src/jobs` contains only BullMQ processors and schedulers; business rules stay in module application/domain services.
- WebSocket gateways live only in `calls` and `presence`; message realtime fanout is driven by events and shared WebSocket infrastructure, not business logic inside gateways.
